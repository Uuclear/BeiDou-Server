# 快速开始

本文档将指导您从零开始搭建BeiDou（北斗）冒险岛服务端开发/运行环境。

## 环境要求

### 必需软件

| 软件 | 版本要求 | 下载地址 | 说明 |
|------|----------|----------|------|
| JDK | OpenJDK 21+ | https://jdk.java.net/archive/ | Java开发运行环境 |
| MySQL | 8.0+ | https://downloads.mysql.com/archives/community/ | 数据库 |
| Maven | 3.8+ | https://maven.apache.org/download.cgi | Java项目构建工具 |
| Git | 最新版 | https://git-scm.com/downloads | 版本控制 |

### 推荐开发工具

| 工具 | 说明 |
|------|------|
| IntelliJ IDEA 2023.3+ | Java IDE（推荐） |
| DBeaver / Navicat | 数据库可视化工具 |
| VS Code | 脚本编辑 |

### 客户端要求

服务端支持 **冒险岛v83版本** 客户端。可从项目Release页面下载配套客户端。

## 环境搭建步骤

### 1. 安装JDK 21

1. 下载OpenJDK 21并安装
2. 配置环境变量 `JAVA_HOME` 指向JDK安装目录
3. 将 `%JAVA_HOME%/bin` 添加到PATH
4. 验证安装：
   ```bash
   java -version
   javac -version
   ```
   应显示Java 21版本信息。

### 2. 安装MySQL 8

1. 下载并安装MySQL 8.0+
2. 设置root用户密码（默认配置为root/root，可修改）
3. 确保MySQL服务已启动
4. **注意**：不需要手动创建数据库，服务端首次启动会自动创建

### 3. 安装Maven

1. 下载Maven并解压
2. 配置环境变量 `MAVEN_HOME`
3. 将 `%MAVEN_HOME%/bin` 添加到PATH
4. （可选）配置Maven镜像源加速（阿里云镜像）
5. 验证安装：
   ```bash
   mvn -version
   ```

### 4. 获取源代码

```bash
git clone https://github.com/BeiDouMS/BeiDou-Server.git
cd BeiDou-Server/gms-server
```

## 服务端配置

### 数据库配置

编辑配置文件 `src/main/resources/application.yml`：

```yaml
mybatis-flex:
  datasource:
    mysql:
      url: jdbc:mysql://localhost:3306/beidou?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
      username: root
      password: root  # 修改为你的MySQL密码
```

**配置项说明：**
- `url`: 数据库连接URL，`beidou`为数据库名（首次启动自动创建）
- `username`: 数据库用户名
- `password`: 数据库密码
- `serverTimezone`: 时区设置，建议使用`Asia/Shanghai`

### 服务器网络配置

```yaml
gms:
  service:
    language: zh-CN  # 语言：zh-CN(中文) / en-US(英文)
    wan-host: 127.0.0.1   # 公网IP（外网部署时修改）
    lan-host: 127.0.0.1   # 局域网IP
    localhost: 127.0.0.1  # 本地回环地址
    login-port: 8484      # 游戏登录端口
```

### JWT配置（Web管理后台）

```yaml
jwt:
  secret: "your-uuid-secret"  # 生产环境请自行生成UUID
  duration: 1800000           # Token过期时间（毫秒），默认30分钟
```

### Swagger配置

开发环境可开启Swagger UI方便调试：

```yaml
springdoc:
  api-docs:
    enabled: true  # 生产环境设为false
  swagger-ui:
    enabled: true  # 生产环境设为false
```

开启后访问：http://localhost:8686/swagger-ui/index.html

## 启动服务端

### 方式一：IDEA启动（开发推荐）

1. 使用IntelliJ IDEA打开 `gms-server` 目录
2. 等待Maven自动下载依赖
3. 找到主类 `org.gms.ServerApplication`
4. 右键 → Run 'ServerApplication'
5. **重要**：如果是直接打开Cosmic目录运行，需要在运行配置中设置 Working directory 为 `gms-server`

### 方式二：Maven命令启动

```bash
cd gms-server
mvn spring-boot:run
```

### 方式三：打包后启动

```bash
cd gms-server
mvn clean package -DskipTests
java -jar target/BeiDou.jar
```

### 方式四：使用启动脚本

**Windows：**
```batch
launch.bat
```

**Linux/Mac：**
```bash
chmod +x launch.sh
./launch.sh
```

## 首次启动

1. 启动时控制台会输出初始化日志
2. 服务端会自动：
   - 连接MySQL（连接到mysql系统库）
   - 创建`beidou`数据库（如果不存在）
   - 执行Flyway数据库迁移脚本（创建所有表并初始化数据）
   - 启动登录服务器（端口8484）
   - 启动Web API服务（端口8686）
3. 看到类似以下日志表示启动成功：
   ```
   Started ServerApplication in X.XXX seconds
   Login Server started on port 8484
   ```

## 客户端连接

### 使用配套客户端

1. 从项目[Release页面](https://github.com/BeiDouMS/BeiDou-Server/releases)下载客户端
2. 解压客户端
3. 修改客户端的服务端IP配置（通常在`localhost.txt`或登录器配置中）
4. 启动客户端，使用默认管理员账号登录：
   - 账号：`admin`
   - 密码：`admin`

### 默认账号

首次启动后，系统会创建默认管理员账号：
- **管理员账号**：admin / admin
- **权限等级**：最高GM权限

**⚠️ 安全提示**：首次登录后请立即修改默认密码！

## 验证安装

1. **数据库验证**：连接MySQL，检查`beidou`数据库是否创建，是否有80+张数据表
2. **端口验证**：
   - 8484端口：游戏登录端口
   - 8686端口：Web管理API端口
3. **Web API验证**：访问 http://localhost:8686/swagger-ui/index.html 查看API文档
4. **客户端登录**：使用客户端连接服务器并成功登录

## Web管理后台

Web管理前端项目为 `gms-ui`（本仓库仅包含服务端）：

1. 安装NodeJS v20.15.0
2. 安装Yarn：`npm install -g yarn`
3. 进入gms-ui目录执行：`yarn install`
4. 启动开发服务器：`yarn dev`
5. 访问 http://localhost:8787

## 常见启动问题

### 问题1：数据库连接失败

**症状**：启动时报数据库连接错误

**解决方案**：
- 确认MySQL服务已启动
- 检查application.yml中的数据库用户名密码是否正确
- 确认MySQL版本为8.0+（不支持MySQL 5.x）
- 检查数据库用户是否有足够权限（需要创建数据库权限）

### 问题2：端口被占用

**症状**：启动时报端口绑定失败

**解决方案**：
- 检查8484和8686端口是否被其他程序占用
- Windows：`netstat -ano | findstr "8484"`
- Linux：`netstat -tlnp | grep 8484`
- 关闭占用端口的程序或修改配置文件中的端口

### 问题3：WZ文件加载失败

**症状**：启动时WZ相关报错

**解决方案**：
- 确认`wz/`目录存在且包含XML文件
- 确认工作目录（Working directory）设置正确，应为gms-server目录

### 问题4：IDEA中找不到主类

**解决方案**：
- 确认是打开gms-server目录，而不是父目录
- 等待Maven导入完成
- 重新导入Maven项目：右键pom.xml → Maven → Reload project
