# 项目目录结构

本文档详细说明 GMS Server（BeiDou）项目的目录结构及其用途。

## 一、根目录文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `pom.xml` | Maven 项目配置文件，定义项目依赖、构建配置、插件等。项目使用 Java 21，基于 Spring Boot 3.2.3 构建，核心依赖包括 Netty 4.1.109（网络通信）、GraalVM JS（脚本引擎）、MyBatis-Flex（ORM）、Druid（数据库连接池）、Flyway（数据库迁移）、Log4j2（日志）等。 |
| `README.md` | 项目说明文档，包含开发准备、数据库配置、IDEA 配置等信息。 |
| `launch.sh` | Linux/Mac 启动脚本，使用内置 JRE 启动服务端：`./jdk-21.0.11+10-jre/bin/java -jar BeiDou.jar` |
| `launch.bat` | Windows 启动脚本，功能同 launch.sh，设置 UTF-8 编码后启动服务端。 |
| `.gitignore` | Git 忽略配置，忽略 target、build、out、logs、static、docker-db-data、.idea 等目录。 |
| `BeiDou.jar` | 编译打包后的可执行 JAR 文件（构建后生成）。 |

## 二、源代码目录结构（src/main/java/org/gms/）

### 2.1 config - 配置类

Spring Boot 配置类，负责服务器各项配置的初始化：

| 类名 | 说明 |
|------|------|
| `GameConfig` | 游戏核心配置，管理游戏各项参数（经验倍率、掉率、活动开关等） |
| `ServerConfig` | 服务器配置，管理网络、世界、频道等服务器参数 |
| `SpringSecurityConfig` | Spring Security 安全配置，Web API 认证授权 |

### 2.3 model - 数据模型

- **dto/**：数据传输对象，用于 API 请求和响应

  - 响应 DTO：`ResultBody`、`WorldListRtnDTO`、`ChrOnlineListRtnDTO`、`InventorySearchRtnDTO` 等
- **pojo/**：普通 Java 对象，用于业务逻辑中间数据

### 2.5 dao - 数据访问层

数据库访问层，使用 MyBatis-Flex ORM 框架：

- **entity/**：数据库实体类，对应数据库表结构
- **mapper/**：MyBatis Mapper 接口，定义数据库操作方法

### 2.6 net - 网络通信模块

核心网络层，基于 Netty 实现，处理客户端连接和数据包：

- **netty/**：Netty 服务器实现
  - `AbstractServer`：服务器抽象基类
  - `LoginServer`：登录服务器，处理账号登录、世界选择、频道选择
  - `ChannelServer`：频道服务器，处理游戏内所有逻辑
  - `LoginServerInitializer`/`ChannelServerInitializer`：通道初始化器
  - `ServerChannelInitializer`：通道初始化基类，配置 Pipeline
  - `PacketCodec`：数据包编解码器
  - `InvalidPacketHeaderException`：无效数据包头部异常

- **encryption/**：加密解密模块
  - `PacketEncoder`：数据包编码器
  - `PacketDecoder`：数据包解码器
  - `MapleAESOFB`：AES OFB 模式加密（冒险岛自定义加密）
  - `MapleCustomEncryption`：冒险岛自定义加密算法
  - `InitializationVector`：初始化向量（IV）管理
  - `ClientCyphers`：客户端加密器集合
  - `protocol/`：协议版本工厂

- **packet/**：数据包定义
  - `Packet`：数据包接口
  - `InPacket`/`OutPacket`：入站/出站数据包接口
  - `ByteBufInPacket`/`ByteBufOutPacket`：基于 Netty ByteBuf 的实现
  - `out/`：出站数据包构造类（各种发送给客户端的封包）
  - `logging/`：数据包日志记录

- **opcodes/**：操作码定义，发送和接收数据包的操作码常量

- **PacketProcessor**：数据包处理器，将操作码映射到对应的 Handler
- **PacketHandler**/`AbstractPacketHandler`：数据包处理器接口和基类
- **ChannelDependencies**：频道依赖注入

### 2.7 net.server - 服务器端核心

游戏服务器核心逻辑：

- **Server**：服务器主类，管理世界、频道、登录服务器
- **channel/**：频道相关
  - `Channel`：频道类，管理单个频道的所有在线角色、地图、NPC、怪物等
  - `CharacterIdChannelPair`：角色ID与频道映射
  - `handlers/`：频道数据包处理器（所有游戏内操作的处理类）

- **world/**：世界相关
  - `World`：世界类，管理多个频道
  - `Party`/`PartyCharacter`：组队及组队成员
  - `Messenger`/`MessengerCharacter`：聊天窗/ Messenger
  - `PartyOperation`：组队操作枚举

- **guild/**：公会相关
  - `Guild`：公会类
  - `GuildCharacter`：公会成员
  - `GuildSummary`：公会摘要
  - `Alliance`：联盟（多个公会组成）
  - `GuildPackets`：公会相关封包
  - `GuildResponse`：公会响应枚举

- **services/**：服务调度
  - `type/`：服务类型枚举（World/Channel 服务）
  - `task/`：定时任务
    - `world/`：世界级定时任务（角色保存、事件调度等）
    - `channel/`：频道级定时任务（怪物刷新、地图更新等）

- **task/`：服务器定时任务

- **coordinator/**：协调器
  - `session/`：会话协调，管理连接生命周期
  - `login/`：登录协调
  - `world/`：世界协调，邀请协调（组队、公会、交易等）
  - `partysearch/`：组队搜索协调
  - `matchchecker/`：匹配检查（交易、组队、公会等匹配验证）

- **handlers/login/**：登录阶段数据包处理器
- `PlayerBuffValueHolder`/`PlayerCoolDownValueHolder`：玩家 Buff 和冷却值持有器

## 三、资源目录结构（src/main/resources/）

| 文件/目录 | 说明 |
|-----------|------|
| `application.yml` | Spring Boot 主配置文件，包含：<br>- 服务器端口（默认 8686）<br>- 数据库连接（MySQL beidou 库）<br>- JWT 配置<br>- MyBatis-Flex 配置<br>- Flyway 配置<br>- 游戏语言设置（zh-CN/en-US）<br>- 网络配置（登录端口 8484，频道端口范围）<br>- 限流配置 |
| `banner.txt` | 服务器启动时显示的 ASCII Art Banner |
| `log4j2.xml` | Log4j2 日志配置，配置日志级别、输出格式、文件滚动等 |
| `db/migration/` | Flyway 数据库迁移脚本，按版本号命名：<br>- V1.0.x__create_xxx.sql：创建表结构（账号、角色、背包、公会、好友、任务、技能、婚姻、家族、扭蛋等共 60+ 表）<br>- V1.0.x__xxx_insert_data.sql：初始数据插入<br>- V1.x.x__update_xxx.sql：后续版本更新脚本 |
| `i18n/` | 国际化资源文件：<br>- `message_zh_CN.properties`/`message_en_US.properties`：消息文本<br>- `exception_zh_CN.properties`/`exception_en_US.properties`：异常信息<br>- `log_zh_CN.properties`/`log_en_US.properties`：日志消息 |

## 四、WZ 资源目录（wz/）

WZ 是冒险岛的资源文件格式，XML 格式导出，包含游戏所有静态数据：

| 目录 | 说明 |
|------|------|
| `Base.wz/` | 基础资源，包含游戏通用设置、wz 基础数据 |
| `Character.wz/` | 角色资源，包含各职业、发型、脸型、装备外观等角色相关数据（武器、帽子、衣服、鞋子等的 sprite 信息） |
| `Effect.wz/` | 特效资源，包含技能特效、UI 特效、场景特效等 |
| `Etc.wz/` | 其他资源，包含椅子、坐骑等杂项数据 |
| `Item.wz/` | 物品资源，包含所有物品图标、装备图标、道具数据（分 Consume、Etc、Cash、Install、Pet 等子目录） |
| `Map.wz/` | 地图资源，包含地图背景、地形、地图数据、世界地图信息（分 Map、MapHelper 等子目录） |
| `Mob.wz/` | 怪物资源，包含怪物数据、怪物动作、怪物技能等（每个怪物 ID 对应一个 img.xml） |
| `Morph.wz/` | 变身资源，包含变身状态的数据 |
| `Npc.wz/` | NPC 资源，包含 NPC 数据、NPC 图像、NPC 对话等（每个 NPC ID 对应一个 img.xml） |
| `Quest.wz/` | 任务资源，包含任务信息、任务要求、任务奖励数据 |

## 五、脚本目录（scripts/ 和 scripts-zh-CN/）

两个目录结构相同，分别对应英文和中文脚本：

| 目录/文件 | 说明 |
|-----------|------|
| `NPC Base.js` | NPC 脚本基类，提供 NPC 脚本的基础 API 和函数 |
| `QUEST Base.js` | 任务脚本基类，提供任务脚本的基础 API |
| `REACT Base.js` | 反应器脚本基类 |
| `devtest.js` | 开发测试脚本 |
| `npc/` | NPC 对话脚本目录，文件名为 NPC ID.js（如 1002000.js、9010000.js 等），每个 NPC 对应一个脚本文件，定义 NPC 对话、商店、任务、转职等逻辑 |
| `quest/` | 任务脚本目录，文件名为任务 ID.js（如 1021.js、20000.js 等），定义任务开始、完成、超时等自定义逻辑 |
| `event/` | 活动事件脚本目录：<br>- 副本活动：`ZakumBattle.js`（扎昆）、`HorntailBattle.js`（暗黑龙王）、`PinkBeanBattle.js`（品克缤）、`PapulatusBattle.js`（闹钟）等<br>- 组队任务：`KerningPQ.js`（废弃组队）、`LudiPQ.js`（玩具组队）、`OrbisPQ.js`（天空组队）、`EllinPQ.js`（艾琳组队）、`HenesysPQ.js`（月妙组队）、`GuildQuest.js`（公会任务）等<br>- 交通：`Boats.js`（飞船）、`Trains.js`（列车）、`Cabin.js`、`Genie.js`、`Elevator.js` 等<br>- 区域BOSS：`AreaBoss*.js`（各区域 BOSS 刷新脚本）<br>- 其他活动：`2xEvent.js`（双倍经验）、Wedding（婚礼）等 |
