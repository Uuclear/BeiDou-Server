## 脚本概述

BeiDou服务端使用GraalVM JS引擎执行JavaScript脚本，支持游戏内容的热更新而无需重启服务器。

### 1. 脚本目录结构

```
scripts/
├── npc/          # NPC对话脚本（文件名：NPC ID.js）
├── quest/        # 任务脚本（文件名：任务ID.js）
├── reactor/      # 反应堆/机关脚本（文件名：反应堆ID.js）
├── portal/       # 传送门脚本（文件名：传送门脚本名.js）
├── map/          # 地图脚本（文件名：地图ID.js）
├── event/        # 事件/副本脚本（自定义文件名）
├── item/         # 物品使用脚本（文件名：物品ID.js）
├── NPC Base.js   # NPC脚本基础模板
├── QUEST Base.js # 任务脚本基础模板
└── REACT Base.js # 反应堆脚本基础模板
```

> 中文脚本放在 `scripts-zh-CN/` 目录下，结构相同。

### 2. 脚本管理器对象

| 对象名 | 类型 | 说明 | 可用脚本 |
|--------|------|------|----------|
| `cm` | NPCConversationManager | NPC对话管理器 | NPC脚本、物品脚本 |
| `qm` | QuestActionManager | 任务管理器 | 任务脚本 |
| `rm` | ReactorActionManager | 反应堆动作管理器 | 反应堆脚本 |
| `pm` | PortalPlayerInteraction | 传送门交互管理器 | 传送门脚本 |
| `em` | EventManager | 事件管理器 | 事件脚本 |
| `eim` | EventInstanceManager | 事件实例管理器 | 事件脚本 |
| `im` | ItemScriptMethods | 物品脚本方法 | 物品脚本 |

### 3. 脚本热重载

游戏内GM命令：
- `!reloadevents` - 重载所有事件、NPC、任务脚本
- 或通过Web管理后台文件编辑保存后自动重载

## NPC脚本开发

NPC脚本用于处理玩家与NPC的交互，包括对话、商店、传送、任务等。

### 1. 基础模板

文件：`scripts/npc/1002000.js`（以NPC ID命名）

```javascript
/**
 * NPC脚本基础模板
 * NPC名称：示例NPC
 * 所在地图：弓箭手村
 */
var status;

/**
 * 对话开始 - 玩家点击NPC时自动调用
 */
function start() {
    status = -1;
    action(1, 0, 0);
}

/**
 * 处理玩家对话动作
 * @param {number} mode - 操作模式：1=确认/下一个，0=否/返回上一个，-1=关闭对话
 * @param {number} type - 对话类型
 * @param {number} selection - 选择的选项索引
 */
function action(mode, type, selection) {
    if (mode == -1) {
        // 玩家关闭对话
        cm.dispose();
    } else {
        if (mode == 0 && type > 0) {
            cm.dispose();
            return;
        }
        if (mode == 1) {
            status++;
        } else {
            status--;
        }

        if (status == 0) {
            // 第一段对话
            cm.sendOk("你好，冒险者！欢迎来到弓箭手村。");
            cm.dispose();
        }
    }
}
```

### 2. 对话API详解

#### 2.1 基础对话方法

| 方法 | 说明 | 后续操作 |
|------|------|----------|
| `cm.sendNext(text)` | 显示带"下一个"按钮的对话 | 点击下一个后mode=1继续 |
| `cm.sendPrev(text)` | 显示带"上一个"按钮的对话 | 点击上一个后mode=0返回 |
| `cm.sendNextPrev(text)` | 同时显示上一个/下一个按钮 | 用于多页对话 |
| `cm.sendOk(text)` | 显示"确定"按钮的对话 | 点击确定后对话继续或结束 |
| `cm.sendYesNo(text)` | 显示是/否选择 | selection=0(是), 1(否) |
| `cm.sendAcceptDecline(text)` | 显示接受/拒绝选择 | 常用于任务确认 |
| `cm.sendSimple(text)` | 显示选择菜单 | 使用#L选项#l语法 |
| `cm.sendGetNumber(text, def, min, max)` | 显示数字输入框 | selection为输入的数字 |
| `cm.sendGetText(text)` | 显示文本输入框 | 使用cm.getText()获取输入 |
| `cm.sendStyle(text, styles)` | 显示发型/脸型选择 | selection为选择的样式索引 |

#### 2.2 对话文本颜色代码

| 代码 | 效果 |
|------|------|
| `#b文字#k` | 蓝色文字 |
| `#r文字#k` | 红色文字 |
| `#g文字#k` | 绿色文字 |
| `#e文字#n` | 粗体文字 |
| `#L数字#选项文字#l` | 可点击的选项链接 |

#### 2.3 选择菜单示例

```javascript
function action(mode, type, selection) {
    if (mode == -1) {
        cm.dispose();
    } else {
        if (mode == 1) status++;
        else status--;

        if (status == 0) {
            var text = "你好，需要什么帮助吗？\r\n";
            text += "#L0#我想看看商店#l\r\n";
            text += "#L1#请把我传送到弓箭手村#l\r\n";
            text += "#L2#给我一些药水#l\r\n";
            text += "#L3#没什么事#l";
            cm.sendSimple(text);
        } else if (status == 1) {
            if (selection == 0) {
                // 打开商店
                cm.openShopNPC(1002000);
                cm.dispose();
            } else if (selection == 1) {
                // 传送
                cm.warp(100000000);  // 弓箭手村
                cm.dispose();
            } else if (selection == 2) {
                // 给物品
                if (cm.canHold(2000000, 50)) {
                    cm.gainItem(2000000, 50);  // 白色药水x50
                    cm.sendOk("给你50瓶白色药水！");
                } else {
                    cm.sendOk("你的背包已满！");
                }
                cm.dispose();
            } else if (selection == 3) {
                cm.sendOk("再见！");
                cm.dispose();
            }
        }
    }
}
```

## 任务脚本开发

任务脚本用于自定义任务的开始和完成逻辑。

### 1. 基础结构

任务脚本需要实现两个函数：
- `start(mode, type, selection)` - 任务开始时的对话
- `end(mode, type, selection)` - 任务完成时的对话

文件：`scripts/quest/20000.js`（以任务ID命名）

```javascript
var status = -1;

/**
 * 任务开始函数
 * 玩家点击NPC开始任务时调用
 */
function start(mode, type, selection) {
    if (mode == -1) {
        qm.dispose();
    } else {
        if (mode > 0) status++;
        else status--;

        if (status == 0) {
            qm.sendNext("你好，年轻的冒险者。我有一个任务交给你...");
        } else if (status == 1) {
            qm.sendNextPrev("请帮我收集50个蜗牛壳，它们可以在魔法森林附近找到。");
        } else if (status == 2) {
            qm.sendAcceptDecline("你愿意接受这个任务吗？");
        } else if (status == 3) {
            if (mode == 1) {
                qm.forceStartQuest();
                qm.sendOk("任务已接受！收集完蜗牛壳后回来找我。");
            } else {
                qm.sendOk("没关系，等你准备好了再来。");
            }
            qm.dispose();
        }
    }
}

/**
 * 任务完成函数
 * 玩家完成任务条件后点击NPC时调用
 */
function end(mode, type, selection) {
    if (mode == -1) {
        qm.dispose();
    } else {
        if (mode > 0) status++;
        else status--;

        if (status == 0) {
            if (qm.haveItem(4000000, 50)) {
                qm.sendYesNo("你收集到蜗牛壳了吗？");
            } else {
                qm.sendOk("你还没有收集够50个蜗牛壳，继续努力！");
                qm.dispose();
            }
        } else if (status == 1) {
            if (mode == 1) {
                // 扣除任务物品
                qm.gainItem(4000000, -50);
                // 发放奖励
                qm.gainExp(500);
                qm.gainMeso(10000);
                qm.gainItem(2000000, 50);
                // 完成任务
                qm.forceCompleteQuest();
                qm.sendOk("做得好！这是给你的奖励：500经验、10000金币、50瓶白色药水。");
            }
            qm.dispose();
        }
    }
}
```

### 2. 任务条件检查

```javascript

        } else if (status == 1) {

                        em.startInstance(cm.getParty(), cm.getMap());
                        cm.dispose();

                    }
                }
            }
            cm.dispose();
        }
```
